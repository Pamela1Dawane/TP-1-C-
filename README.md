# TP 1 - C#

Exercícios desenvolvidos durante as aulas de C# utilizando o Visual Studio.

## Exercícios

- Exercício 06 - Debug e troca de variáveis
- Exercício 08 - Entrada de dados do usuário
- Exercício 09 - Leitura e conversão de dados
- Exercício 10 - Declaração e impressão de variáveis

## Objetivo

Praticar os fundamentos da linguagem C#, incluindo variáveis, entrada de dados, conversão de tipos, estruturas básicas e depuração.

## Ambiente

- C#
- .NET 8
- Visual Studio 2022
